# AroundWire‑WP

🌐 **AroundWire‑WP** — marketing website built with **WordPress**.  
This repository contains the WordPress theme and assets for the official **AroundWire Pro** landing site — a promotional platform designed to showcase features, blog content, SEO, and lead generation for the AroundWire social marketplace.

## 🚀 Overview

The site is a **WordPress theme** that includes:

✔️ Custom page templates for landing and content pages  
✔️ Blog listing and single post templates  
✔️ Search functionality  
✔️ Responsive layout with CSS and JS assets  
✔️ Custom theme parts (header, footer, templates)  
✔️ Utility scripts and styles for UI interactions  
✔️ Designed to support content marketing and conversion optimization

## 🧠 Technologies Used

✔️ **WordPress** — CMS and theme engine  
✔️ **PHP** — server‑side templates and WordPress functions  
✔️ **CSS (responsive)** — styling and layout  
✔️ **JavaScript** — UI interactions and enhancements  
✔️ WordPress template hierarchy and theme support

## 📦 Installation

1. Clone this repository:  
   ```bash
   git clone https://github.com/Karataev-Daniil/AroundWire-WP.git
Copy the theme folder into your WordPress installation:

wp-content/themes/aroundwire‑wp
Activate the theme from the WordPress dashboard (Appearance → Themes).

Configure pages, menus, blog settings, and any required plugins.

📌 Usage
This theme powers a marketing and content site — it includes layouts for blog posts, landing pages, and search views. It’s built to serve:

✔️ Product promotion and feature pages
✔️ SEO‑optimized blog content
✔️ Lead capture (via forms configured in WordPress)
✔️ Brand messaging and content marketing
